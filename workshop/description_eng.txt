[TAROT SATCHEL]

Turn tarot cards into a one-shot resource that drops naturally and can be used outside combat.

FEATURES
- Win a combat to roll for a tarot drop with an adaptive pity system: 15% initially, +10% on a miss, -20% on a drop, +12.5% on elites; boss fights use the same chance as normal combats.
- A dropped tarot appears as a reward on the combat reward screen; claim it to store it in the satchel on the top bar.
- The satchel sits opposite the potion bar, holds 2 tarots by default and stays visible like the potion bar.
- Outside combat, click a tarot icon to Use / Discard; slots cannot be used during combat.
- Using a tarot adds it to your draw pile at the start of your next combat, where it can be played normally.
- One-shot: when that combat ends it is removed from the pile whether you played it or not, and it never enters your persistent deck.
- The drop is pre-rolled and written at each official checkpoint, so loading a save, save & quit and QuickSL reloads never reroll: pity and satchel state stay consistent.

SCOPE
- All characters, including modded ones; no ascension changes.
- Uses the game's existing 22-card tarot pool; adds no new cards.
- No dependencies on other mods.

INSTALL
- Subscribe on the Steam Workshop and enable it, or drop the mod folder into the game's mods folder and launch the game through Steam.
- This mod changes gameplay: it uses modded saves, and every player needs it installed for multiplayer.

KNOWN LIMITATIONS
- Multiplayer: satchel contents are tracked locally per player and are not synced.
- Combat encounters started from event options (for example the beloved double-robot brawl event) do not drop tarots for now.

MOD COMPATIBILITY
- Tested together with: QuickSL, BaseLib, MintySpire2, Intent Graph and LieRenTVmod.
